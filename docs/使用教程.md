# MemeR-AI图文视频印记数据清理：中文使用教程

## 1. 选择使用方式

MemeR-AI 提供两种入口：

- 独立 EXE：适合手动选择文件、查看进度和打开可视化报告。
- Codex Skill：适合让 Codex 批量处理目录、读取 JSON 报告并自动汇总结论。

两种入口使用同一清理核心，输出结果一致。

## 2. 安装 Codex Skill

打开 PowerShell，粘贴并运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/sanadayu3/memer-ai-media-mark-cleaner/main/install.ps1 | iex"
```

安装器会：

1. 查询 GitHub 最新 Release。
2. 下载 Skill 文件、共享 Windows 运行包和 SHA-256 校验文件。
3. 分别核对下载文件是否完整。
4. 自动把 GUI/CLI 运行包组装进 Skill。
5. 把已有版本备份到带时间戳的文件夹。
6. 安装到 `%USERPROFILE%\.codex\skills\memer-ai-media-mark-cleaner`。

完成后重新打开 Codex或新建任务。

## 3. 在 Codex 中使用

清理单个文件：

```text
使用 $memer-ai-media-mark-cleaner 清理 D:\素材\input.mp4，
输出到 D:\素材\metadata_cleaned，并告诉我清除了哪些字段。
```

批量清理文件夹：

```text
使用 $memer-ai-media-mark-cleaner 批量清理 D:\素材\待发布，
输出到 D:\素材\已清理；完成后读取 JSON 报告，汇总 REMOVED、REMAINS 和 ERROR。
```

只扫描：

```text
使用 $memer-ai-media-mark-cleaner 扫描 D:\素材\待检查，只检查不生成清理文件。
```

启动 GUI：

```text
使用 $memer-ai-media-mark-cleaner 启动图形界面。
```

## 4. 使用独立 EXE

1. 从 GitHub Releases 下载 `MemeR-AI-Media-Mark-Cleaner-portable.zip`。
2. 完整解压 ZIP。
3. 双击 `MemeR-AI图文视频印记数据清理.exe`。
4. 使用“添加文件”或“添加文件夹”导入素材。
5. 选择输出目录。
6. 点击“开始清理”。
7. 等待每个文件显示处理结果。
8. 点击“打开可视化报告”。

不要只复制 EXE；必须保留 `_internal` 文件夹。

## 5. 处理策略

### 图片

图片会重新保存像素内容，尽量不保留原始 EXIF、XMP、ICC、提示词、工作流、软件名和作者字段。重新保存可能轻微改变文件大小或压缩细节。

### 视频

视频统一输出为：

- MP4 容器
- H.264 视频
- `yuv420p` 像素格式
- AAC 128k 音频
- 不保留字幕轨、数据轨和章节
- 清空普通 metadata，并用 ExifTool 做第二轮清理

## 6. 阅读报告

### HTML

`clean_report.html` 适合人工检查。顶部显示处理文件数、成功数、已清除数量和残留数量；下面按文件列出具体字段。

### TXT

`clean_report.txt` 是便于搜索和归档的逐项记录。

### JSON

`clean_report.json` 适合 Codex 或脚本读取，主要字段包括：

- `source`：源文件。
- `output`：清理后文件。
- `removed_traces`：已清除字段。
- `remaining_traces`：复查残留字段。
- `errors`：处理错误。

## 7. 如何判断结果

- `REMOVED`：清理前存在，清理后复查不再出现。
- `REMAINS`：清理后仍然存在，应人工确认。
- `ERROR`：不能视为成功，需要检查输入文件或错误信息。

MP4 的 `handler_name`、`HandlerDescription`、codec `encoder` 可能是封装器生成的结构默认值，不一定表示 AI 来源。

残留为 0 只说明文件层扫描未再命中。隐形水印、图像或声音内容特征、平台风控、账号行为等不在本工具能力范围内。

## 8. 更新、恢复与卸载

更新时重新运行一键安装命令即可。旧版本会自动备份。

需要恢复时：

1. 关闭 Codex。
2. 删除或改名当前 `memer-ai-media-mark-cleaner` 文件夹。
3. 把需要恢复的 `.backup-时间戳` 文件夹改回 `memer-ai-media-mark-cleaner`。

卸载时删除 `%USERPROFILE%\.codex\skills\memer-ai-media-mark-cleaner`，然后重新打开 Codex。

## 9. 使用边界

本工具只做文件层元数据清理与误标风险排查：

- 不删除隐形水印。
- 不改变画面、声音、口型和动作等内容特征。
- 不承诺平台无法识别 AI 内容。
- 不替代平台要求的 AI 内容披露。
